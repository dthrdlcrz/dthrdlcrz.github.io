# dthrdlcrz-portfolio

Personal portfolio of **Diether Garcia Dela Cruz** — Lead Software Developer & Automation Developer.

Built with React + Vite. Deployed on GitHub Pages.

🔗 [Live Site](https://dthrdlcrz.github.io/dthrdlcrz-portfolio/)

## Tech Stack
- React 18
- Vite 5
- CSS Modules

## Getting Started

```bash
cd app
npm install
npm run dev
```

## Deploy to GitHub Pages

```bash
cd app
npm run deploy
```
